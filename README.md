# Mestre Ciclista — web

Web de una sola página para Mestre Ciclista, taller de bicicletas.

- `index.html`: la web completa (estilos, script y logos incluidos en el archivo).
- `logos/`: logos de las marcas con las que trabaja el taller (Larry vs Harry, Omnium y Autonocleta) en PNG transparente.

Las fotos se cargan desde el álbum compartido de Google Fotos del cliente. Para cambiarlas, busca `FOTO` en `index.html`.
La galería "Nuestro día a día" muestra 12 fotos al azar cada vez que se entra; para añadir fotos, edita la lista `GALERIA` al final de `index.html`.
